# Student Toolkit Website (Day 1)

This is a beginner-level multi-page website built using **HTML** and **CSS**.  
It is designed to help students manage their timetable, assignments, and useful study resources in one place.

## Features
- Multi-page navigation bar
- Timetable page with table layout
- Assignments page (static version)
- Resources page with useful links
- Contact form page

## Technologies Used
- HTML5
- CSS3
- VS Code (Live Server)

## Pages Included
- Home (`index.html`)
- Timetable (`timetable.html`)
- Assignments (`assignments.html`)
- Resources (`resources.html`)
- Contact (`contact.html`)

## Future Improvements
- Add a real interactive assignments tracker using JavaScript
- Store assignments using localStorage
- Improve UI and responsiveness for mobile devices
